# 交互设计规范

本文档定义 wb-convo-flow 的交互规则，作为后续迭代的一致性基准。

## 1. 总体结构

```
┌──────────────────────────────────────────────────┐
│ Toolbar: logo | 画布/列表 | 工作流菜单 | 画布操作  │
├──────────┬───────────────────────────────────────┤
│ 工作空间  │  主区                                  │
│ 侧栏      │  · 画布模式：FlowCanvas（+模态窗）      │
│ (双模式   │  · 列表模式：ConversationTabs + Viewer │
│  共用)    │                                       │
└──────────┴───────────────────────────────────────┘
```

## 2. 画布布局

- **自动铺开**：进入画布模式（或切换工作空间）时，若新建工作流则把当前空间**全部对话**自动铺上画布。
- **三档尺寸**：按消息数分档——`sm`（<20 条，200px）/ `md`（20~60 条，240px）/ `lg`（>60 条，280px）；卡片左上角有档位徽标（小/中/大）。
- **网格蛇形**：大对话优先排前，每行 4 列，奇数行反向（蛇形阅读动线）；行高按行内最大卡片，小卡片垂直居中。
- **重新铺开 / 重排**：
  - 「重新铺开」= `appendMissing`：只把未入画的对话追加到画布末尾，**不移动**已有节点。
  - 「重排」= `relayout`：全部重算网格位置，**保留连线**；已从磁盘消失的对话作为"孤儿节点"排在末尾。

## 3. 节点卡片

| 区块 | 内容 |
|------|------|
| 头部 | 档位徽标 + 标题（超长省略，悬停显全称） |
| 摘要 | 首条用户提问的两行预览（120 字封顶） |
| 元信息 | 消息数 · 更新日期 |
| 「下一」行 | 时间上紧邻的下一个对话，**一键连接**（已连显示"已连"并置灰） |
| 操作 | 预览（模态窗）/ 连接→（连接选择器）/ 删除 |

- **单击**：选中（多选按住 `Shift`）。
- **双击**：通过 `workbuddy://chat/<uuid>` 深链唤起 WorkBuddy 主窗口，打开该对话的**原生完整形态**（未响应时 Toast 提示确认 WorkBuddy 已运行）。
- **拖拽**：移动位置（拖起即记录撤销历史）。
- **Delete/Backspace**：删除选中节点/连线。

## 4. 连线

四种建立方式，可任意混用：

1. **端口拉线**（Langflow/Dify 风格）：从节点右侧 source 端口拖到目标节点左侧 target 端口。
2. **连接选择器**：点卡片「连接→」弹出浮层，两个 Tab 找目标——
   - **搜索**：按标题/摘要实时过滤，`Enter` 直连第一个结果；
   - **时间线**：按更新时间倒序的紧凑列表点选。
   选中后自动**飞行定位**到目标节点（高亮 2 秒）；同时保持画布可点（浮层开着时直接点击画布节点也能连）。
3. **相邻快速连接**：卡片「下一」行一键连接时间上紧邻的下一个对话。
4. **框选批量自动串联**：Shift/框选 ≥2 个节点后，画布底部浮出操作条，**由使用者选择排序**（更新时间正序 / 创建时间正序 / 消息数降序）后一键按序首尾串联。

规则：

- **方向完全自由**（任意两节点可连），仅阻止自连、重复连线与**成环**（DFS 检测）。
- 重复/成环/目标未入画时以 Toast 给出原因。
- 连线样式：smoothstep 折线 + 流动动画；新建连线的目标节点短暂高亮。
- 删除连线：点选连线后按 `Delete`。

## 5. 对话查看（双形态）

- **深链跳转（主）**：双击节点 → `workbuddy://chat/<uuid>` → WorkBuddy 主窗口原生对话完整形态。深链由 WorkBuddy 桌面端注册（应用内含 `workbuddy://chat/`、`workbuddy://task?action=start` 等路由）；未响应时 Toast 提示确认 WorkBuddy 已运行。
- **画布内预览（辅）**：卡片「预览」→ 模态窗只读浏览完整消息流（角色气泡、模型名、时间戳）；底部沿当前连线跳转上/下一节点；模态头部另有「在 WorkBuddy 打开」深链按钮。
- 关闭模态：`Esc`、右上 ✕、点击遮罩空白。

## 6. 工作流管理

- 每个工作空间独立的命名工作流列表；顶部下拉切换。
- **自动暂存**：任何节点/边变更后 0.8s 防抖写入 `draft: true`（不覆盖 `savedAt`）。
- **显式保存**：「保存」按钮写入正式版本并刷新 `savedAt`；列表中未保存的工作流显示「暂存」徽标。
- 新建：输入名称（Enter 确认），新建后自动铺开当前空间全部对话。
- 重命名：✎ 行内编辑；删除：✕ + 确认弹窗；导出：下载 JSON。
- 删除当前工作流后自动切换到剩余第一个，或新建空工作流。

## 7. 快捷键

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+Z` | 撤销 |
| `Ctrl+Shift+Z` | 重做 |
| `Delete` / `Backspace` | 删除选中节点/连线 |
| `Shift+点选` | 多选 |
| `Esc` | 取消连线 / 关闭模态窗 |

## 8. 列表模式

保留 Tab 标签页形态：点击工作空间后中间区域以 Tab 展示每个对话，标签内为消息流。定位是"快速浏览"，画布模式是"结构编排"，二者共享同一份工作空间数据，一键切换。
